# Asset Attribution

## Models

Every model under `public/models/island/` is original work by Qiran Hu, generated by the Blender scripts in
`blender/island/` in this repository (design spec in `blender/DESIGN.md`). No third-party model ships with the site.

## Third-party files

### Poly Haven textures (CC0)

These textures are downloaded from Poly Haven and are licensed under CC0 (see `https://polyhaven.com/license`).

- `public/textures/hq/cliff_side/*`: Cliff Side (`https://polyhaven.com/a/cliff_side`)
- `public/textures/hq/cobblestone_pavement/*`: Cobblestone Pavement (`https://polyhaven.com/a/cobblestone_pavement`)
- `public/textures/hq/sparse_grass/*`: Sparse Grass (`https://polyhaven.com/a/sparse_grass`)

### Runtime decoders (Apache 2.0)

- `public/draco/*`: Draco geometry decoder by Google, as shipped with the three.js examples (`https://github.com/google/draco`)
- `public/examples/jsm/libs/basis/*`: Basis Universal transcoder by Binomial, as shipped with the three.js examples (`https://github.com/BinomialLLC/basis_universal`)
